# PWA-іконки

Використовуються в `app/manifest.js` для "Додати на головний екран" на
Android/Chrome/iOS (apple-touch-icon у `app/layout.js` — той самий
icon-192.png, окремого файлу нема).

Перегенеровані за проханням користувача: кремовий фон (`#FAF8F1`, той
самий тон, що й раніше) БЕЗ зеленої рамки-обводки, символ — суцільний
трилисток `public/assets/brand/trefoil-solid-green.png` замість
wordmark "Carlsberg" (той був нечитабельний на реальному розмірі
іконки — дрібний текст зливався в пляму). `icon-192.png`/`icon-512.png`
— заокруглений квадрат із прозорими кутами (OS сама накладає маску);
`icon-maskable-512.png` — суцільний квадрат без заокруглення й без
прозорості (спец. maskable-іконок: OS сама обрізає під свою форму,
контент має лишатись у безпечній зоні ~50% канви).
