# PWA-іконки

Скопійовано з `legacy/assets/` (icon-192.png/icon-512.png/icon-maskable-512.png)
— ті самі офіційні іконки, що вже використовувались у vanilla-JS версії
застосунку (`legacy/manifest.json`), а не щось новостворене. Використовуються
в `app/manifest.js` для "Додати на головний екран" на Android/Chrome.
