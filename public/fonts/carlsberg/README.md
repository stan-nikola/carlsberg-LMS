# Carlsberg Sans

Офіційний фірмовий шрифт Carlsberg Group (друкарський, з Corporate Visual
Identity Designguide v1, лютий 2017). Файли надані користувачем
(співробітником Carlsberg Ukraine) з внутрішнього ліцензійного пакету
`Carlsberg Sans v3100` — власність Carlsberg Group, використовується лише
для внутрішніх продуктів компанії. Не поширювати за межами проєкту.

Тут лишені лише web-формати (`.woff2`, варіант `W00`), реально
використовувані через `next/font/local` (див. `app/layout.js`) — Light
(300), Bold (700) і Black (900), кожен зі своїм italic-різом. Перевірено
безпосередньо по гліфах шрифта (fontkit): кирилиця та специфічно
українські літери і/ї/є/ґ присутні у всіх шести файлах.

Оригінальний пакет також містив OTF/TTF/EOT-варіанти й другий hinting-
набір (`W05`, гліфи ідентичні `W00`) — не закомічені, щоб не роздувати
репозиторій дублікатами того самого шрифту в форматах, які тут не
використовуються.
