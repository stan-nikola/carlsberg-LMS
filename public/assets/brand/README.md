# Crafted hops leaf

Офіційний графічний елемент Carlsberg Group ("crafted hops leaf" —
інтерпретація фірмового знаку-хмелю, брендбук стор. 27-38). Джерело —
пакет `Carlsberg_Hops_Crafted_{Large,Small}.zip`, наданий користувачем
(внутрішній ліцензійний Carlsberg-актив; `ai_Professional_use` +
`Office_use_RGB/emf`, не веб-формати).

Ці PNG — растеризація офіційних `.emf`-варіантів через нативний Windows
`System.Drawing` (без сторонніх растеризаторів, які могли б спотворити
рукописні лінії), прозорий фон, антиаліасинг:
- `hops-leaf-small-green.png` — малий лист, Carlsberg green, для
  розміщення на білому/світлому фоні.
- `hops-leaf-small-white.png` — той самий малий лист, білий — для
  розміщення на зеленому/темному фоні (на білому прев'ю виглядає
  порожнім — це очікувано, він для іншого фону).
- `hops-leaf-large-green.png` — великий лист, Carlsberg green.

Правило використання з брендбуку: subtle, tone-in-tone, opacity 20-45%
залежно від фону — НЕ основний елемент, лише декоративна текстура.
Оригінальні `.ai`/`.emf`-файли (CMYK/Pantone-варіанти, інші кольори з
palette) не закомічені — за потреби взяти в користувача повторно.

## trefoil-solid-green.png

Окремий асет — суцільний (не лінійний) трилисток, наданий користувачем
напряму. На відміну від `hops-leaf-*` вище (тонка ручна лінійна графіка,
задумана як decorative texture за брендбуком), цей — суцільна заливка:
лишається чітким навіть на малих розмірах (PWA-іконка, ~60px і менше),
де `hops-leaf-small-green.png` "зливається" в пляму (лінії надто тонкі
для такого масштабу). Використовується як основний PWA-логотип
(public/icons/icon-*.png) — не декоративний елемент, сам знак.
